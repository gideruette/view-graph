Hiding & tags

Extractors label nodes with tags (tech:angular, type:service, …). The Tags tab on the left turns them into bulk operations: 👁 hides every node carrying a tag plus the branches only they reached, only hides every other tag in the same namespace, and the swatch paints every node carrying the tag.
One node at a time: H (or Hide in the detail panel) takes it off the canvas, and + tag in the detail panel adds your own tag — which then hides and colours exactly like an extractor's. All of it persists across reloads; Show all in the filter bar puts everything back.
